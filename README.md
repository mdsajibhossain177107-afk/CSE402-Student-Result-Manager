
# CSE402 - Student Result Manager

## Project Overview
Student Result Manager is a Python application designed to help teachers manage student academic results.

## Functional Requirements

1. Add a student with a unique ID and name.
2. Add a course with course code, title, and credit.
3. Enter student marks out of 100.
4. Calculate letter grades and grade points.
5. Calculate student CGPA based on course credits.
6. Display student result sheets.
